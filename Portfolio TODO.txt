ARCHITECTURE & CONTENT MAINTENANCE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• To update profile/contact/summary → edit src/data/portfolioData.js (profile object)
• To add/edit professional skill groups → edit professionalSkills in portfolioData.js
• To add a project → append to the projects array in PortfolioSection.js
• To add a technology → add to techCategories in SkillsAndCertsSection.js
• To add a certificate → add to qualifications in SkillsAndCertsSection.js
• To update CV or Certificates PDF → replace files in src/assets/certs/
• Build: cd portfolio && npm run build
• Test:  cd portfolio && CI=true npm test
